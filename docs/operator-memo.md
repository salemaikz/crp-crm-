# Памятка оператора: CRM с телефона

Один лист A4. Подписи в `{}` подставляются из настроек компании: `{eventShort}` —
групповое мероприятие, `{consultShort}` — индивидуальная консультация,
`{eventLong}` и `{consultLong}` — их полные названия. Источник логики —
`docs/PROCESS.md` (§2.5–2.7, §3.2, §3.4, §6). Пример для первого клиента —
`presets/clients/crp/operator-memo.md`.

## 1. Вход и выход
- Откройте CRM, введите **номер телефона** и **пароль**, нажмите «Войти». Ссылку
  для первого пароля даёт руководитель; не работает — попросите новую.
- Выход: «Выйти». Если есть неотправленные итоги, CRM сначала отправляет их
  («Отправляем итоги…»). Не ушли: «Остаться» или «Всё равно выйти».
- **Общий телефон:** в конце смены всегда выходите. «Всё равно выйти» — только
  когда сети нет и ждать нельзя: итоги останутся на этом телефоне и уйдут при
  следующем входе **под вашим же логином**. Если телефон сдаёте, сначала дождитесь
  отправки. Потеряли телефон — «Мой аккаунт» → «Выйти на всех устройствах».

## 2. Экран «Звонить»
- Сверху: «К звонку сейчас: N · просрочено: M». Вкладки: **Все / Перезвоны /
  Повторы / Новые**. Ниже — одна карточка: название, ЛПР, «Попытка N», последний
  итог, последняя заметка, номера.
- Порядок очереди задаёт система. «Пропустить» — лимит в день («Пропущено
  сегодня: N из M»); без сети пропустить нельзя. Очередь пуста — ждите раздачи.
- «Карточка» открывает клиента целиком: номера, контакты, ленту, записи.

## 3. Звонок и итог
1. «**Позвонить**» открывает звонилку телефона (у второго номера — «Позвонить на
   второй номер»). Нет номера — откройте карточку и добавьте.
2. После разговора вернитесь в CRM: сама откроется шторка «**Итог звонка**». Не
   открылась — «Указать итог звонка».
3. Выберите итог. После нажатия в течение 5 секунд есть «Отменить»; потом итог
   уходит на сервер, отменить нельзя.

| Итог (подпись задаёт компания) | Когда ставить | Что дальше |
|---|---|---|
| **Не берёт** | не взяли, отключён, занято, сбросили до разговора | одно нажатие; повтор через 2 часа, затем следующий рабочий день 10:00; 3-й недозвон подряд — карточка «Списан» |
| **Номер не работает** | номера не существует или он не той компании; не выключен! | выберите причину; есть другой номер — звоните по нему, нет — «Списан»; найденный новый номер добавьте сразу |
| **Перезвонить** | договорились созвониться | нужны дата и время (быстрые: «Через 2 ч», «Завтра 10:00», «Другое»); появится задача «Перезвонить» |
| **Договорились — записать** | клиент согласен на шаг | ЛПР, контакт «кто придёт», запись (п. 5) или дата договорённости; только онлайн, отмены 5 секунд нет |
| **Не интересует** | отказ сейчас | причина обязательна (напр. нет потребности, дорого, позже); карточка вернётся через время |
| **Не целевой** | компания не подходит (закрылась, госорган, не тот регион) | причина; закрыто, вернуть может только РОП |
| **Полный отказ** | просит больше не звонить | причина; номер уйдёт в стоп-лист. «Не звонить и по этим номерам» — по желанию |

- **Повторы и перезвоны.** Недозвоны ставит в очередь сама система («Повторы»);
  договорённые перезвоны — во вкладке «Перезвоны» и в «Задачах». Любой дозвон
  обнуляет счётчик попыток. Звонили с другого телефона — внесите итог так же
  через шторку (будет пометка «внесено вручную»).
- **ЛПР** (лицо, принимающее решение). При «Перезвонить», «Договорились», «Не
  интересует» отметьте **Да/Нет**: говорили ли с ним. «Нет» — заполните хотя бы
  одно из полей «Имя ЛПР», «Прямой номер», «Когда звонить» или напишите заметку.
- **Заметка** — коротко и по делу (что решили, что просил): её увидит следующий
  звонивший. Без реальных паспортных и платёжных данных.

### Причина и срок перезвона
Действует, когда компания включит причины и сроки перезвона (флаг `CALLBACK_V2`).
Печатать к этому дню вместо строки «Перезвонить» из таблицы выше.
- «**Перезвонить**» → выберите **причину** (список задаёт компания; «Другое» —
  с коротким текстом). Если компания сделала причину обязательной, без неё итог
  не сохранится.
- **Срок предлагает CRM** по номеру касания: «2-е касание · через 7 дней — пт
  30.10». Это подсказка: смените дату чипами «Завтра», «Через неделю» или
  «Другая дата».
- **Время необязательно.** Переключатель «Указать время» выключен — перезвон
  «в течение дня»: карточка встаёт в очередь с начала окна звонков, огонёк горит
  весь день, просроченным срок станет только на следующий день. Договорились на
  точное время — включите переключатель и укажите его.
- Причины «не пришёл» и «пришёл, не купил» CRM ставит сама после отметки явки;
  если явку ещё не отметили, их можно выбрать вручную. Системные причины
  (например, повторная продажа) в списке не показываются.

## 4. Запись
- «Договорились — записать» → «**Записать клиента**» открывает мастер «Запись».
  Вкладки «Что назначаем».
- **{eventShort}** ({eventLong}): выберите ближайшую дату — видно «Осталось N из
  M», затем «Подтвердить». Мест нет — «Другая дата».
- **{consultShort}** ({consultLong}): направление → день → время → консультант
  или «Без консультанта — назначит руководитель» (это **заявка на консультацию**:
  консультанта назначит руководитель, вы ничего не делаете). Занято — «Это время
  уже занято», выберите другое.
- Ошиблись: сразу «Отменить» в плашке; позже — отмена записи в карточке.
- Нет сети или не успеваете — «Запишу позже»: итог сохранится, появится задача
  «Записать: договорились».
- Список «Записи»: напомнить сегодня/завтра (откроется WhatsApp с готовым
  текстом), ответ клиента отметьте: подтвердил, перенести, отменил.

## 5. Клиенты и задачи
- «Клиенты» → «**Мои клиенты**» — те, с кем вы работаете. Поиск: от 3 букв названия
  или 5 цифр номера. Чужие карточки не открываются.
- «**Предложить контакт**»: номер телефона и название компании → «Отправить».
  Карточка попадёт в очередь после проверки руководителем.
- «**Задачи**»: Просрочено / Сегодня / Завтра / Позже. Выполнили — «Готово».
  «Задача» создаёт свою (клиент обязателен, срок — быстрые кнопки или «Своё»).

## 6. Нет сети и «Не отправлено»
- Без сети итоги не пропадают: «Нет сети, итоги сохранены», они уйдут сами,
  когда связь вернётся. Не закрывайте вкладку и не чистите данные браузера.
- «**Не отправлено: N**» — столько итогов ещё на вашем телефоне. Подождите
  связь; руководитель видит эту цифру у каждого оператора.
- «Итог не принят: …» — сервер отклонил (например, карточка передана
  другому). Нажмите «Понятно» и, если нужно, сообщите руководителю.
- «Память телефона недоступна» — итоги не переживут закрытие вкладки: не закрывайте.
- Без сети нельзя: «Пропустить», «Договорились — записать». Для них — «Запишу позже».

## 7. Если что-то пошло не так
1. «Очередь не загрузилась» — проверьте сеть, «Повторить».
2. «Данные изменились» — обновите страницу и повторите действие.
3. Не вошли: проверьте номер и пароль; «Слишком много попыток» — подождите
   указанные секунды. Забыли пароль — к руководителю.
4. Не помогло — сообщите руководителю: что нажимали, что написано на экране
   (скриншот без лишних данных клиента). Не пытайтесь «починить» повторными
   итогами: сервер дубль не создаст, но путаница в очереди возможна.
