# Воронка v2, круг 2: доработка интерфейса к старту операторов (~30.10)

Статус: план architect, 24.10. Визуальные правила — `docs/ui-polish-design.md` §9, решение D-353 «предложено».
Базовая ветка линий — `wt/pv2-fix`; каждая линия — своя ветка `wt/pv2-<ключ>` от неё и свой worktree.

Источник — шесть аудитов стенда (телефон, ноутбук, карточка, аналитика, понятность, сверка с требованиями) против
Pipedrive, amoCRM, Битрикс24 и HubSpot. Каждая находка проверена по коду `wt/pv2-fix` (a161182). Дубли сведены,
ложные и уже исправленные выкинуты (§1.3).

## 0. Коротко

- **P0 — 11 находок, все в плане**: вкладки под кнопками плиток (звонок не тому клиенту), «Покупка» и «Мусор» за
  краем ноутбука, колонки без своей прокрутки, «Мусор» с погашенной кнопкой без причины и три одинаковых
  «Другое (текст)» с разными последствиями, срок перезвона не подставлен, шторка лида без контекста и действий,
  звонок в ленте без итога и заметки, памятка без доски. Воронка директора > 100 % уже исправлена (d10f436), остаток —
  P1.
- **P1** — взяты те, что помещаются в ~1 день каждой из четырёх линий и не требуют новых ключей настроек, миграций и
  новых маршрутов с записью. Остальное — §6 с причиной.
- **Новых ключей настроек нет** (схема v1 заморожена 26.10 12:00, D-346), **миграций нет**, **зависимостей нет**.
  Новый маршрут один — страница `/help` (чтение, `page()`, манифест). Всё за существующими флагами `OP_BOARD`,
  `CALLBACK_V2`, `THEME_DARK`.
- Четыре линии: **board**, **shell**, **card**, **anl**. Зоны не пересекаются; общие `src/ui/kit/**`,
  `src/ui/tokens.css`, `src/ui/theme/**`, `messages/ru/common.json` — только у **board**.

## 2. Общие правила

Нормативно — `docs/ui-polish-design.md` §9 (D-353): слои, сетка колонок, плотность плитки на телефоне и ноутбуке,
тоны признаков (зелёный — «был на групповом», жёлтый — «был на консультации», из `board.tones` пресета), выбранное и
погашенное, шапка доски, шторка лида, оболочка оператора на ноутбуке, подписи из настроек, приёмка §9.10.

Плюс правила AGENTS для всех линий: SQL только в `repo`-файлах домена; охват `scopeSql`; «чужое = 404»; обёртки и
манифест изоляции; тексты — `messages/ru/*`; специфика клиента — только в пресете; синтетика `+7 709`; исправление
бага начинается с падающего теста; тесты не ослабляются, `skip`/`only` нельзя.

### 3.2. Контракты между линиями (фиксируются здесь, реализуются независимо)

- **К1. Адрес доски** (`/board` и `/deals/calling`): `tab=<ключ колонки>`, `q=<текст ≤ 100>`, `sort=heat|due|new`,
  `f=<фильтр>[,<фильтр>]` из `BOARD_FILTERS`, `owner=<userId>` и `reason=<код>` — только у доски пространства.
  Неизвестное значение молча отбрасывается (проверка по конфигу доски), запись в адрес — `router.replace` без новой
  записи истории. Делает board (B7); ссылки строят card (C5) и anl (A7).
- **К2. Превью ленты**: card экспортирует `src/app/(op)/clients/_ui/FeedPreview.tsx`
  (`{clientId, labels: FeedLabels, limit?: number}`, клиентский, читает `GET /api/clients/[id]/feed?limit=N`) и
  серверную `feedLabelsFor(viewer)` (`src/app/(op)/clients/_ui/feedLabels.server.ts`) — те же подписи, что у
  «Истории». board кладёт `feedLabels` в конфиг доски (`loadBoardConfig`) и рисует `FeedPreview` в шторке. card
  вливает C2 первым; до влития board оставляет в шторке ссылку «Вся история».
- **К3. Возврат из карточки**: шторка строит `href = /clients/{id}?from=board&tab={колонка}` у оператора и
  `?from=deals&tab=…` на доске пространства (board, B5); карточка рисует «← К доске» на `/board?tab=…` или
  `/deals/calling?tab=…` (card, C5). `from` — закрытый список, `tab` — `[a-z0-9_]{1,32}`.
- **К4. Меню и справка**: id пунктов `purchases` (оператор) и `board` (менеджерская оболочка, `/deals/calling`) —
  shell; якоря страницы `/help`: `board`, `move`, `trash`, `callback`, `attend`, `purchases` — shell; ссылка «?» с
  доски ведёт на `/help#board` — board.
- **К5. Доска РОП без `KANBAN`**: при `OP_BOARD` страница `/deals/calling` и её список сотрудников работают при
  выключенном `KANBAN` (anl, A8); пункт меню `board` — только `feature: 'OP_BOARD'` (shell, S2).

## 7. Вопросы владельцу

- **В-К2-1. Одно название консультации.** Сейчас у клиента колонка «Консультация», вид записи «Бизнес-консультация»,
  короткая подпись «БК». **Рекомендую:** длинная подпись вида — «Консультация» (как колонка), короткая «БК» — только
  в узких местах с полной подписью в подсказке; «Бизнес-разбор» / «БР» без изменений. Это правка значений настроек
  установки, не кода.
- **В-К2-2. Обзвон «подтвердить явку».** Старт операторов около 30.10, первый четверг после него — 05.11.
  **Рекомендую:** выпустить обзвон подтверждения отдельной линией до 04.11; до неё на плитке «Бизнес-разбора» виден
  статус записи «Подтвердил / Не подтвердил», а подтверждение ставится как сейчас — в записи.
