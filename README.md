# CRM отдела продаж

Узкая CRM для отдела продаж, который работает по телефону. Это продукт
SalemAI. Каждый клиент получает свою установку на своём сервере в Казахстане,
со своей БД и лицензией.

Что умеет: обзвон «одна карточка за раз» с итогом в одно нажатие и работой
без сети; раздача базы с дневным лимитом и рабочим календарём; импорт таблиц и
приём лидов по API; запись на групповые мероприятия и консультации, явка;
сделки, покупки и передача в другой отдел; задачи; карточка клиента с
настраиваемыми полями и полной историей; канбан; базовые отчёты; уведомления;
роли с охватами («оператор видит только своё»). Телефония и WhatsApp
(Wazzup) подключаются через плагины. Режим телефонии по умолчанию — `manual`:
кнопка открывает звонилку телефона.

Всё, что относится к конкретной компании (типы мероприятий, итоги, лимиты,
роли, поля, бренд, город), задаётся пресетом и настройками, а не кодом.
Первый клиент — ЦРП (Центр Развития Предпринимателей, Астана).

## Запуск локально

> Каркас создаётся 21.10 (задача P1 в `docs/PLAN.md`). Если команды ниже
> разойдутся с `package.json`, исправляется этот README.

Нужно: Node 22, Docker (для Postgres 16), npm.

```bash
npm ci
docker compose -f deploy/compose.dev.yml up -d db    # Postgres 16 на localhost:5432
cp deploy/env/app.env.example .env.local             # только синтетические значения
npm run db:migrate                                   # миграции из migrations/
npm run seed:demo                                    # синтетика: номера +7 709 …, выдуманные компании
npm run dev                                          # http://localhost:3000
npm run worker                                       # фоновые задачи (раздача, сводки)
```

Проверки перед пушем:

```bash
npx tsc --noEmit
npm run lint
npm run test:unit
npm run test:integration      # нужен Postgres 16 (TEST_DATABASE_URL)
npm run test:isolation        # оператор не видит чужое
npm run test:e2e              # Playwright, мобильные размеры
```

Реальные данные клиентов на локальной машине и в ИИ-сессиях не используются.
Только синтетика.
