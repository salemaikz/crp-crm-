Шрифты пресета `geologica_onest` (локальные файлы, запросов к сторонним сервисам нет).
Источник: пакеты npm `@fontsource-variable/geologica` 5.3.0 и `@fontsource-variable/onest` 5.3.1
(контрольные суммы tarball сверены с реестром), переменная ось wght 100–900, подмножества
latin, cyrillic, cyrillic-ext (казахские буквы — в cyrillic-ext). Лицензия SIL OFL 1.1 — файлы OFL-*.txt.
Подключаются в `src/app/fonts.ts` через next/font/local.
